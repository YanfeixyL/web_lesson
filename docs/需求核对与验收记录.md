## 本次修复的主要问题

1. 运行时的JSON模型没有使用实际持久化框架，改为Sequelize加SQLite，并保留MySQL配置。
2. 管理员账号原为admin/admin123，按PDF改为新库中的admin/admin。
3. 需求列表原来只返回status=0，归档后本人也查不到；现默认返回全部状态。
4. 附件原只有后台接口，现补齐发布、响应和编辑表单的文件入口及下载。
5. 原统计忽略regionId，且拼接每月31日可能跨月；现使用有效月份和左闭右开区间。
6. 原接受流程逐条写入且可重复产生成功明细，现使用事务、唯一约束和单进程写队列。
7. 补齐响应默认状态，修复空状态筛选参数和管理员标签切换时的异步旧结果覆盖。
